

# HandControl Museum｜手势交互虚拟博物馆

基于 Unity 与 Python 开发的三维虚拟博物馆，面向中国传统艺术展示。通过摄像头识别双手手势，让用户完成展馆漫游、展品查看与交互操作。

## 项目演示



## 主要功能

- **展馆漫游**：通过手势控制人物移动与观察视角。
- **展品交互**：支持展品选择、旋转和信息查看。
- **展品导航**：通过手势触发展品导航功能。
- **展示操作**：支持展示页面翻页与选择。
- **山水画体验**：提供山水画“入画”体验。

## 技术实现

- **Unity / C#**：三维场景、界面与交互逻辑。
- **Python / OpenCV**：摄像头画面采集与处理。
- **MediaPipe Hands**：手部关键点检测，结合手指角度与距离判断手势。
- **UDP 通信**：将 Python 识别结果实时传递给 Unity。


## 代码目录

- `Python/`：手势识别与数据发送代码。
- `Unity/`：Unity 工程与交互代码。
